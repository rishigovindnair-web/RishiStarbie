# 3D models

The footprints look for these files in this folder. They came with the Starbie care package and aren't checked in yet, so KiCad's 3D viewer will show those parts as missing. Editing the schematic and PCB works fine without them.

Drop the files here with these exact names to get the full 3D view back:

- `Seeed Studio XIAO-ESP32-C3.step`
- `0.96'' OLED Display.step`
- `GY-521_MPU6050 Accelerometer.step`
- `Cherry MX.STEP`
- `DSA_Keycap_CherryMX.step`
